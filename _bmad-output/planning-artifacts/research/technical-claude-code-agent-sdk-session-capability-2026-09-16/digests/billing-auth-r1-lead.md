# Digest: Billing & credential resolution — round 1, lead (first-hand)

Source: https://code.claude.com/docs/en/authentication (Anthropic, official Claude Code docs). Accessed 2026-09-16. No publication date shown on page; content references Claude Code versions up to v2.1.265, so the page is current to at least that release.

## Decisive quotes

**B-1. The full authentication precedence list**, quoted verbatim under the heading "Authentication precedence" — "When multiple credentials are present, Claude Code chooses one in this order:"

1. Cloud provider credentials, when `CLAUDE_CODE_USE_BEDROCK`, `CLAUDE_CODE_USE_VERTEX`, or `CLAUDE_CODE_USE_FOUNDRY` is set.
2. `ANTHROPIC_AUTH_TOKEN` environment variable. Sent as the `Authorization: Bearer` header.
3. `ANTHROPIC_API_KEY` environment variable. Sent as the `X-Api-Key` header.
4. `apiKeyHelper` script output.
5. `CLAUDE_CODE_OAUTH_TOKEN` environment variable. "A long-lived OAuth token generated by `claude setup-token`."
6. Anthropic profile and federation credentials.
7. Subscription OAuth credentials from `/login`. "This is the default for Claude Pro, Max, Team, and Enterprise users."

**B-2. The Agent SDK is explicitly named as inheriting this resolution.** Direct quote: "`apiKeyHelper`, `ANTHROPIC_API_KEY`, and `ANTHROPIC_AUTH_TOKEN` apply to the CLI and the surfaces that wrap it, including the VS Code extension, the Agent SDK, and GitHub Actions."

**B-3. The Agent SDK is explicitly named as a subscription login path.** Direct quote: "Developers can log in from several paths: the terminal `/login` flow, the VS Code extension, the Agent SDK, `claude setup-token`, `/install-github-app`, and gateway sign-in..."

**B-4. `claude setup-token` binds to a subscription, not an API key.** Direct quote: "This token authenticates with your Claude subscription and requires a Pro, Max, Team, or Enterprise plan. It can only make model requests..."

**B-5. API key wins over subscription when both are present.** Direct quote: "If you have an active Claude subscription but also have `ANTHROPIC_API_KEY` set in your environment, Claude Code uses the API key once you approve it." And, decisively for an unattended host process: "In non-interactive mode (`-p`), the key is always used when present."

**B-6. Bare mode is API-key-only.** Direct quote: "Bare mode does not read `CLAUDE_CODE_OAUTH_TOKEN`. If your script passes `--bare`, authenticate with `ANTHROPIC_API_KEY` or an `apiKeyHelper` instead."

**B-7. Cloud provider credentials outrank everything and bill elsewhere.** Bedrock / Google Cloud's Agent Platform / Microsoft Foundry are selected by env var and sit at precedence 1.

## Claims

| # | Claim | Confidence | Class |
|---|---|---|---|
| B1 | A programmatically driven Claude Code / Agent SDK session can be billed to EITHER an Anthropic API key OR a Claude subscription. Both are supported; neither is required. | high | capability |
| B2 | Which one is used is determined by a documented, deterministic 7-step credential precedence order, keyed on environment variables and stored credentials. | high | capability |
| B3 | For a non-interactive host process, `ANTHROPIC_API_KEY` present means the API key is always used — no prompt, no fallback to subscription. | high | capability |
| B4 | Subscription billing for an unattended host process is reached via `CLAUDE_CODE_OAUTH_TOKEN`, minted by `claude setup-token`, requiring a Pro/Max/Team/Enterprise plan. | high | capability |
| B5 | `--bare` mode narrows the choice: it refuses `CLAUDE_CODE_OAUTH_TOKEN` and requires an API key or `apiKeyHelper`. | high | capability |
