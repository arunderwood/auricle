# D1 landscape digest

Scope: on-device English ASR on Apple-silicon macOS, screened for a 20-40 min far-field multi-speaker meeting use case. Budget spent: 17 tool calls, 9 sources read (one Apple doc fetch returned an empty body). All claims below were retrieved 2026-09-21; anything older than its freshness bar is marked STALE.

## Leads

- Contradiction: the WhisperKit releases fetch reported v1.1.0 as "August 6, 2024" and v1.0.0 as "May 1, 2024", but a second source says v1.0.0 shipped May 2026 and the release content (Swift 6, Pyannote 4, Qwen3-TTS) is 2025-2026 tech. Re-fetch the releases page directly (or `gh release list -R argmaxinc/WhisperKit`) to pin dates.
- FluidAudio README says weights are "MIT/Apache 2.0"; NVIDIA Parakeet TDT is CC-BY-4.0 upstream. Check `nvidia/parakeet-tdt-0.6b-v3` model card before relying on the FluidAudio statement.
- Apple `apple/coreai-models` repo now hosts Parakeet v3 (issue #163 requests v2) — an Apple-maintained Core ML conversion would change the maintenance-risk picture for finalist #2.
- Argmax blog "Apple SpeechAnalyzer and Argmax WhisperKit" (https://www.argmaxinc.com/blog/apple-and-argmax) — vendor comparison of the two; not read.
- Open ASR Leaderboard long-form track as of Sept 2026: which of Cohere Transcribe 2B, Granite Speech 4.1, Voxtral Transcribe 2, Qwen3-ASR lead long-form specifically (Nov 2025 snapshot had Whisper large-v3 on top). The leaderboard Gradio space was not fetched.
- `mlx-audio-swift` package: does it expose Voxtral/Qwen3-ASR/Parakeet in Swift? README read did not say.
- Whether SpeechTranscriber's `.audioTimeRange` attaches to words or larger runs, and whether it exposes confidence — needed for the attribution stage; WWDC25 session 277 and the "Bringing advanced speech-to-text capabilities to your app" sample are the primary sources.
- Voxtral Mini Transcribe 2.0 (offline, 5.90% avg per the Realtime card's comparison) — separate model card not read; may be the better batch candidate than Realtime.
- Kyutai STT WER numbers live on kyutai.org, not the repo.
- Does WhisperKit v1.1.0 change default decoding (temperature fallback, compression-ratio thresholds, VAD chunking)? Release notes summary did not say; relevant to the "fix decoding settings" branch of the decision.
